## How to use this file

1. Fill in **Your notes / decision** for each row (in your own words — what
   the indicator means to _you_, and whether it should be a gate, a tier
   multiplier, neither, or removed entirely).
2. Once filled, we'll convert each non-empty note into either:
   - a probe (`scripts/probe-level-zones.ts` or similar) to validate,
   - a gate (`qualityGates.<name>` in `HawksTripleScreenConfig`),
   - a tier multiplier (added to `FAVOR_INDICATORS` in `hawks-triple-screen.ts`),
   - or a drop (removed from loader + this inventory).
3. We tackle one row per iteration per the "one-at-a-time" rule.
