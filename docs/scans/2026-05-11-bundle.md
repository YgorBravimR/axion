**Date**: 2026-05-11
**Subject**: #15 from `docs/scan-roi-plan-2026-05-07.md` (Tier C)
**Scope**: whole repo (`package.json`, `src/**`, `scripts/**`)

## Why this subject

Unused dependencies inflate `node_modules`, install time, and (where the bundler can't tree-shake) shipped JS. Unused source files + exports inflate refactor surface and confuse `grep`-driven exploration. The plan called out: install a dedicated detector (knip) and act on its highest-confidence findings.

## Phase 5a — why knip surfaces a lot of noise

Three patterns inflate knip's "unused" lists in this codebase:

1. **Barrel `index.ts` per feature folder** is a project convention but the codebase imports by direct path. The barrels are noise but cheap to keep — removing them is a churn-for-cleanup trade with no runtime win.
2. **One-shot maintenance scripts** (`scripts/migrate-*`, `scripts/backfill-*`) are intentionally kept after running. They're not bundled, so they cost nothing.
3. **Co-exported types** alongside components. Convention is "export the component + its Props type together" even when only the component is imported. Pruning the type breaks the convention.

The signal lives in cluster D — files that aren't barrels, scripts, or co-exported types and have zero importers. The brand-switcher cluster (5 files) is the cleanest example.

## Phase 5c — prevention rules (memory seed)

### Convention

**Removing unused npm deps is a safe-by-default operation when:**

- No source file imports the package name (and no submodule path, e.g. `@radix-ui/foo`)
- The package isn't loaded by a build/runtime config file (`next.config.*`, `tailwind.config.*`, `eslint.config.*`, `playwright.config.*`)
- Lint + typecheck pass after removal

Removing files is **not** safe-by-default. Even with knip flagging zero importers, framework-loaded files (`page.tsx`, `layout.tsx`, `error.tsx`, `loading.tsx`, `not-found.tsx`, `route.ts`) won't show up in knip's static graph if they're inside `src/app/`. Always verify the file isn't framework-conventional before deleting.

### Detector convention

```bash
# Re-run periodically. Anything new in unused-deps is high-confidence fix.
pnpm exec knip --no-config-hints --reporter compact | head -80

# Sanity-check before removing a "unused" file
grep -rn '<file-name>' src/ next.config.ts                  # any importer?
ls src/app | grep -E '(page|layout|error|loading|not-found|route)\.tsx?$'  # framework files
```
